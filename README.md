## 📜 The 12 Laws of the GatiFleet Constitution

1. **Law 1: One Reality (State Reconciliation)** — Physical reality (IoT telemetry) > System State > User Inputs. Continuous 3-way reconciliation resolves discrepancies.
2. **Law 2: Intelligence Threshold** — No autonomous action is dispatched unless confidence exceeds 85%.
3. **Law 3: Dependency Supremacy** — Every operational decision evaluates downstream Knowledge Graph dependencies across connected nodes.
4. **Law 4: Calculation Integrity** — Every calculation generates an explicit, step-by-step mathematical breakdown log for auditability.
5. **Law 5: Evolution Primacy** — System policies and dispatch heuristics automatically evolve based on outcome divergence metrics.
6. **Law 6: Causality** — Every event must specify its root cause and origin vector.
7. **Law 7: Zero Stale State** — Operational data older than 5 minutes is marked stale and triggers re-verification.
8. **Law 8: Human-in-the-Loop Override** — Human operators retain override authority over any AI recommendation.
9. **Law 9: Network Externality Control** — Decisions optimize network efficiency over single-asset gains.
10. **Law 10: Economic Viability** — No trip or contract is dispatched below minimum viable margin thresholds.
11. **Law 11: Reversibility & Circuit Breakers** — Universal Agent Kill Switch instantly halts all L3–L5 AI dispatches system-wide upon operator request.
12. **Law 12: Knowledge Continuity** — Operational lessons are permanently recorded in the Double Timeline Memory Ledger.

## 🖥️ Core Workspaces & Functional Modules

### 1. Sentinel-X Security Fortress (Plane 10 Governance)
- **Universal Agent Kill Switch**: Emergency circuit breaker with status indicator and instant disengage controls.
- **WAF & Threat Radar**: Real-time intrusion detection logging SQL Injection, XSS, and Rate-Limit breaches.
- **Secrets Vault & RBAC**: Masked integration secrets with dynamic MFA passkey verification.

### 2. AI Agents Dashboard (Plane 3 & Multi-Agent Consensus)
- **Agent Autonomy Selectors**: Interactive L0–L5 autonomy dropdowns per agent card.
- **Multi-Agent Adversarial Debate Inspector**: Live consensus evaluator simulating trade-offs between Finance, Logistics, and Risk agents.

### 3. Customer Operating System (16-Tab Enterprise Workspace)
- **Customer Intelligence Core (CIC)**: 6-Brain Customer Digital Twins, health scoring across 5 dimensions, and decision journals.
- **Autonomous Revenue Intelligence Engine (ARIE)**: Opportunity digital twins, buying organization graph, and AI pricing tiers.
- **Autonomous Customer Mobilization System (ACMS)**: 9 parallel mobilization lanes and readiness simulation checks.

### 4. Knowledge Graph Workspace (Plane 4 Relational Ontology)
- **Interactive 3D Graph & 2D Tree Visualizer**: Visual representation of nodes (`Customer`, `Vehicle`, `Driver`, `Route`, `Contract`).
- **Cascade Impact Analysis Solver**: Computes multi-hop domino impacts (revenue-at-risk, SLA penalties) for any node disruption.

### 5. ERP & Compliance Hub (Plane 7 Calculation Engine)
- **Executable Calculation Engine Workspace**: Formula schemas for Net Profit Margin, Dynamic Fuel Surcharge (FSC), and SLA Delay Penalties.
- **Compliance Center**: Live GSTIN reconciliation, FASTag auto-recharge, and E-Way Bill route mismatch verification.

## 🚀 Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm (v10+ recommended)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/thakurcodeshere/GatiFleet.git
   cd GatiFleet
   ```
2. Install npm packages:
   ```bash
   npm install
   ```

### Running Locally (Full Stack)

**1. Start Backend API & Intelligence Engines**
```bash
cd server
npm install
node index.js
```
The backend OS server runs on `http://localhost:3000`.

**2. Start Frontend Dev Server**
Open a new terminal window:
```bash
cd GatiFleet
npm run dev
```
Open `http://localhost:5173` in your browser.
