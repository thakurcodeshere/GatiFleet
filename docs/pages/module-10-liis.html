Module 10 — Logistics Infrastructure Intelligence System (LIIS)

The Logistics Infrastructure Intelligence System (LIIS) manages depot coordinates, warehouse docking slots, and gate throughput levels.

1. Business Goal

Reduce vehicle turnaround time (TAT) at depots by aligning inbound ETA predictions with warehouse labor and docking bay scheduling.

2. Core Components

  • Infrastructure Digital Twin: Models layout configurations for docks, scales, and trailer parking slots.
  • Congestion Index Monitor: Models yard congestion indexes by checking current inbound ETAs against active labor schedules.
  • Dock Allocation Solver: Dynamically updates trailer parking and door assignments based on cargo manifests.

3. Yard Turnaround Flow

sequenceDiagram
    participant Truck as Telematics API
    participant YardGate as gate RFID
    participant LIIS as LIIS Allocator
    participant Dock as Dock Controller
    
    Truck->>LIIS: Transmit Inbound ETA (15m out)
    LIIS->>LIIS: Generate Dock Allocation Proposal
    YardGate->>LIIS: Scan FASTag (Truck enters yard)
    LIIS->>Truck: Transmit Parking Bay Assignment
    Dock->>LIIS: Confirm Loading/Unloading Completed
    LIIS->>YardGate: Authorize Gate Pass Release

4. Event Taxonomy

Event Name Trigger Database / State Changes
INBOUND_ETA_UPDATED Truck telematics updates route duration. Appends details to depot arrival board; updates gate queues.
VEHICLE_ARRIVED_AT_GATE Gate RFID scanner parses FASTag. Sets status to 'In Yard'; updates congestion metrics.
DOCK_COMMITTED Truck backs into assigned loading door. Sets dock status to 'Busy'; initiates turnaround timer.
