Module 8 — Autonomous Transportation Planning & Dispatch System (ATPDS)

The Autonomous Transportation Planning & Dispatch System (ATPDS) is GatiFleet's core routing engine, executing transit optimization solutions across India's highways.

1. Business Goal

Reduce logistics operating expenses (empty kilometers, fuel use, drivers overtime) while maximizing SLA delivery compliance.

2. System Components

  • Unified Transportation Graph: Models depots, warehouses, checkpoints, and highway corridors (e.g. NH48, NH44) as nodes and edges.
  • Multi-Objective Solver: Runs optimization algorithms to weigh travel duration and fuel overheads against driver rest schedules.
  • Dynamic Re-Optimization Engine: Instantly modifies shipment assignments if roadblocks, mechanical failures, or border delays occur.

3. Dispatch Planning Flow

graph LR
    Booking[New Shipment Booking] --> Solver[Multi-Objective Solver]
    Solver --> Path[Identify Route Options]
    Path --> Check{Driver Rest & Telematics OK?}
    Check -->|Yes| Dispatch[Assign Driver & Vehicle]
    Check -->|No| Solver
    Dispatch --> Track[Monitor Telematics]

4. Event Taxonomy

Event Name Trigger Database / State Changes
ROUTE_PLAN_GENERATED Dispatch solver completes pathway calculations. Saves active path checkpoints; reserves vehicle/driver slot.
DISPATCH_COMMITTED Planner confirms route or AI agent triggers autogo. Updates shipment state to 'Dispatched'; transmits details to driver portal.
ROUTE_DEVIATION_ALERT Vehicle GPS drifts from plan corridor by >10km. Flags trip status; initiates recovery desk alerts.
