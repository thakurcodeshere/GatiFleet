Tech Stack & Core APIs

GatiFleet uses a modern Javascript stack built for high telemetry throughput and low compute expenses.

Frontend Technologies

  • Core Framework: React 19 + Vite
  • State Management: React Context + Hooks
  • Mapping & Geospatial: Leaflet & React-Leaflet (WMS integrations, custom layer maps)
  • Charts & Viz: Chart.js & React-Chartjs-2
  • Transitions: Framer Motion + Custom CSS system

Backend Technologies

  • Web API Gateway: Node.js + Express.js
  • Database ORM: Prisma Client
  • Relational DB: SQLite (Local server file, zero compute costs)
  • Real-time Telemetry: Socket.io
  • Process Daemon: PM2 Cluster Engine
  • Security Middlewares: express-rate-limit, cors, helmet

Core REST API Endpoints

Customer Operations

HTTP Method Endpoint Path Payload Details Description
GET /api/customers None Returns list of customers, details, and active health scores.
POST /api/customers { name, gstin, region } Saves new organization; initializes digital twin state.
GET /api/customers/:id/twin None Returns the six-brain states for a customer profile.

Fleet & Tracking

HTTP Method Endpoint Path Payload Details Description
GET /api/fleet None Returns active vehicle registry and telematics status.
POST /api/fleet/telemetry { lat, lng, speed, rpm } Simulates physical vehicle telemetry signals.
GET /api/trips/:id/route None Returns checkpoint nodes and geofence coordinates.

WebSocket Events (Socket.io)

  • subscribe:telemetry (Client -> Server) - Subscribes to live vehicle tracking coordinate updates.
  • telemetry:update (Server -> Client) - Emits coordinate signals, vehicle status, and speed details.
  • incident:warn (Server -> Client) - Alerts client when route anomalies or fatigue events occur.
