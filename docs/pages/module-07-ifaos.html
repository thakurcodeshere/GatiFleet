Module 7 — Intelligent Fleet & Asset Operations System (IFAOS)

The Intelligent Fleet & Asset Operations System (IFAOS) manages GatiFleet's physical assets (trucks, trailers, reefers, tyres) and maps active telemetry feeds.

1. Business Goal

Maximize vehicle uptime and prevent transit breakdowns by computing remaining useful life (RUL) on components and scheduling maintenance dynamically.

2. Core Components

  • Physical Asset Registry: Tracks trucks, reefer temperature controllers, FASTag IDs, and tyre parameters.
  • Telemetry Mapping Engine: Parses engine RPM, fuel level logs, tire pressures, and cold chain temperature segments.
  • Predictive Maintenance Solver: Generates RUL indices (0-100%) for braking pads, battery sets, and engines.

4. Event Taxonomy

Event Name Trigger Database / State Changes
ASSET_TELEMETRY_INGESTED IoT device uploads coordinate or sensor payload. Updates cached asset position; appends trip mileage metrics.
MECHANICAL_FAULT_LOGGED OBD sensor fires engine check flag. Creates a pending maintenance ticket; flags vehicle status.
MAINTENANCE_SCHEDULED RUL drops below the 20% limit. Books repair bay; triggers route re-assignment.
