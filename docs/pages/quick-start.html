Quick Start Guide

Get GatiFleet up and running on your local machine or server. This guide walks you through setting up the 11-Tier full-stack monolith architecture in development mode.

Prerequisites

Ensure you have the following installed on your machine:

  • Node.js: Version 20.x or higher (LTS recommended)
  • SQLite3: For local database storage
  • NPM: Bundled with Node.js

1. Clone the Codebase

Clone the GatiFleet repository to your workspace and navigate into the root directory:

git clone https://github.com/thakurcodeshere/GatiFleet.git
cd GatiFleet

2. Install Dependencies

Install package dependencies for both the frontend client and the backend server:

# Install frontend dependencies
npm install

# Install backend dependencies
cd server
npm install
cd ..

3. Start the Backend API (PM2 Daemon)

The backend API manages real-time socket connections, database querying via Prisma, and background queues. Start it using PM2:

cd server
npx pm2 start ecosystem.config.js

This runs the daemonized Express API server listening on http://localhost:3000.

4. Start the Frontend Dev Server

Open a new terminal window at the GatiFleet root directory and start the Vite development server:

npm run dev

The client interface will boot up instantly and can be accessed at http://localhost:5173.

5. Code Verification

Before committing changes, check for linting errors and syntax standards:

npm run lint
